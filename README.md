# jokenpo

Descrição

Jogo jokenpo comum, onde o jogador tenta ganhar do oponente e há possibilidade de empate.

Como jogar:

- O jogador escolhe entre PEDRA, PAPEL e TESOURA.
- O programa faz uma jogada aleatória e anuncia o resultado (vitória, derrota ou empate).

Como executar

python3 jokenpo.py

Requisitos

- Python 3
